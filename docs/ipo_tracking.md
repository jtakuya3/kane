# IPO追跡システム 指示書

## 概要

毎日20:00 JST に実行される日本株IPO情報の自動チェック・記録システム。
直近・今後のIPO情報を収集し、Notionデータベースに保存・更新する。

---

## 毎日の実行手順

### 1. IPO情報の収集（WebSearchを使用）

以下のサイトから**本日時点のIPO情報**を収集する。優先度順に検索すること：

1. **東証IPO情報**: `site:jpx.co.jp 新規上場 IPO {YYYY年MM月}`
2. **みんかぶIPOカレンダー**: `site:minkabu.jp IPOカレンダー {YYYY年}`
3. **株探IPOカレンダー**: `site:kabutan.jp IPO 新規上場 {YYYY年MM月}`
4. **IPO銘柄一覧（最新）**: `日本 IPO 新規上場 {YYYY年MM月} 銘柄`

収集対象期間：**本日から3ヶ月先まで**のIPO予定

### 2. 収集する情報

各IPO銘柄について以下の情報を収集する（取得できない場合は「-」とする）：

| フィールド | 内容 | 例 |
|-----------|------|-----|
| 銘柄名 | 会社名 | 〇〇株式会社 |
| 証券コード | 4桁のコード | 1234 |
| 上場日 | YYYY-MM-DD形式 | 2025-07-10 |
| 市場区分 | 上場先市場 | グロース / スタンダード / プライム |
| 仮条件（下限） | 円 | 1200 |
| 仮条件（上限） | 円 | 1400 |
| 公開価格 | 円（決定後） | 1350 |
| 公開株数 | 株 | 500000 |
| 主幹事証券 | 幹事会社名 | 野村證券 |
| BB期間（開始） | YYYY-MM-DD | 2025-06-20 |
| BB期間（終了） | YYYY-MM-DD | 2025-06-26 |
| 事業内容 | 1〜2行の説明 | SaaS型の〇〇サービスを提供 |
| ステータス | 現在の状態 | BB中 / 公開価格決定 / 上場済 / 上場前 |
| 初値 | 円（上場後） | 1820 |
| 初値騰落率 | % | +34.8% |

### 3. Notionデータベースへの保存

#### 3-1. データベースの検索または作成

まず `mcp__Notion__notion-search` で **「IPO追跡」** を検索する。

- **既存DBが見つかった場合**: そのデータベースを使用する
- **見つからない場合**: 以下の構造で新規作成する

```
データベース名: IPO追跡
親ページ: （ワークスペースのルート）
```

#### 3-2. データベースのプロパティ構成

新規作成時は以下のプロパティを設定する：

```json
{
  "銘柄名": {"type": "title"},
  "証券コード": {"type": "rich_text"},
  "上場日": {"type": "date"},
  "市場区分": {"type": "select", "options": ["グロース", "スタンダード", "プライム"]},
  "仮条件下限": {"type": "number", "format": "yen"},
  "仮条件上限": {"type": "number", "format": "yen"},
  "公開価格": {"type": "number", "format": "yen"},
  "主幹事証券": {"type": "rich_text"},
  "BB開始日": {"type": "date"},
  "BB終了日": {"type": "date"},
  "事業内容": {"type": "rich_text"},
  "ステータス": {
    "type": "select",
    "options": ["上場前", "BB中", "公開価格決定", "上場済", "中止"]
  },
  "初値": {"type": "number", "format": "yen"},
  "初値騰落率": {"type": "rich_text"},
  "最終更新": {"type": "date"},
  "注目度": {
    "type": "select",
    "options": ["★★★ 高", "★★ 中", "★ 低", "-"]
  }
}
```

#### 3-3. レコードの更新ルール

1. **新規銘柄**: 証券コードが未登録 → 新規ページ作成
2. **既存銘柄**: 証券コードが一致 → 変更があったフィールドのみ更新
3. **ステータス判定**:
   - 本日がBB期間内 → 「BB中」
   - 公開価格が決定済み・上場日前 → 「公開価格決定」
   - 上場日が本日以前かつ初値あり → 「上場済」
   - それ以外 → 「上場前」

### 4. 注目度の自動判定

以下の基準で注目度を設定する：

- **★★★ 高**: 以下のいずれかを満たす
  - 主幹事が「野村證券」「大和証券」「みずほ証券」「SBI証券」
  - 公開株数が少ない（小型IPO）かつ注目業種（AI/SaaS/FinTech/医療）
  - 初値騰落率の予想が+50%超（アナリスト評価が高い）
- **★★ 中**: 上記以外の通常IPO
- **★ 低**: 大型増資・ETF等の一般的でないIPO
- **-**: 情報不足で判断できない

### 5. 日次レポートの出力

実行完了後、以下の形式でサマリーを出力する：

```
=== IPO日次チェック完了 ({YYYY-MM-DD} 実行) ===

【今週のIPO（直近7日間）】
- {上場日} {銘柄名}（{コード}）{市場} 公開価格:{公開価格}円 {注目度}

【来月のIPO予定】
- {上場日} {銘柄名}（{コード}）{市場} 仮条件:{下限}〜{上限}円 {注目度}

【本日の更新内容】
- 新規追加: N件
- 情報更新: N件

Notionデータベース: {DB URL}
```

## エラーハンドリング

| 状況 | 対応 |
|------|------|
| WebSearchで情報が取得できない | 複数サイトで再検索し、取得できた情報のみ保存 |
| Notion APIエラー | エラー内容を出力して処理継続 |
| 証券コードが不明 | コードなしで銘柄名をキーに保存 |
| 情報の矛盾（サイト間で価格差異等） | 複数ソースを確認し、より信頼性の高い情報を採用 |

---

## 注意事項

- 情報は各種公開情報サイトから収集するため、**公式情報と差異が生じる場合がある**
- 投資判断に利用する場合は必ず**公式情報を確認**すること
- データは参考情報であり、投資助言ではない
