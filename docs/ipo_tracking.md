# IPOトラッキング指示書

## 概要

毎日20時（JST）に実行される自動IPOチェックタスクの指示書です。
日本市場の新規公開株（IPO）情報を収集し、Google Sheetsに記録・更新します。

## 目的

- 日本市場における新規上場（IPO）予定銘柄の情報を毎日収集する
- 申込期間・上場予定日など重要な日程を追跡する
- Google Sheetsを常に最新の状態に保つ

## 使用ツール

| ツール | 用途 |
|---|---|
| Google Sheets MCP | スプレッドシートの読み書き |
| WebFetch | IPO情報ページの取得 |

## 実行手順

### ステップ1: 既存データの読み込み

Google Sheets MCPを使用して「IPO一覧」シートの全データを読み込む。
既存の企業名・上場予定日のリストを保持しておき、重複チェックに使用する。

### ステップ2: 情報収集

以下のデータソースからIPO情報を収集する。

#### プライマリソース

1. **JPX（日本取引所グループ）新規上場会社情報**
   - URL: `https://www.jpx.co.jp/listing/stocks/new/index.html`
   - 取得内容: 上場予定銘柄一覧、上場日、市場区分、証券コード

2. **みんなのIPO**
   - URL: `https://minkabu.jp/ipo`
   - 取得内容: 申込期間、仮条件、公募価格、主幹事証券

#### セカンダリソース（補完用）

- **IPO BANK**: `https://ipobank.net/`
- **株探 IPO情報**: `https://kabutan.jp/ipo/`

### ステップ3: データの更新

#### 新規銘柄の追加

既存シートに存在しない銘柄を発見した場合:
- 「IPO一覧」シートの末尾に新しい行として追加する
- 取得できた全列を埋める
- ステータスを自動判定（後述）して設定する

#### 既存銘柄の更新

以下の情報が変わった場合のみ該当行を更新する:
- 仮条件が新たに決定・変更された
- 公募価格が新たに決定された
- 申込期間が変更された
- 上場予定日が変更・中止された
- ステータスが変化した

更新した行は必ず「最終更新日」列を現在日時に更新する。

#### ステータスの自動判定ルール

今日の日付（JST）を基準に以下のルールで設定する:

| 条件 | ステータス |
|---|---|
| 今日 < 申込期間開始日 | 申込前 |
| 申込期間開始日 ≤ 今日 ≤ 申込期間終了日 | 申込中 |
| 申込期間終了日 < 今日 ≤ 上場予定日 | 申込終了 |
| 今日 > 上場予定日 | 上場済 |
| 上場中止が確認された場合 | 中止 |

### ステップ4: 本日のアクション確認

以下に該当する銘柄を洗い出す（実行ログに記録する）:
- 今日が申込開始日の銘柄
- 今日が申込最終日の銘柄
- 今日が上場日の銘柄
- 仮条件が新たに決定された銘柄

### ステップ5: 実行ログへの記録

「実行ログ」シートの末尾に1行追加し、今回の実行結果を記録する。

## 注意事項

### データ品質

- 日付はすべて `YYYY/MM/DD` 形式で統一する
- 金額はカンマ区切り整数（例：`1,000`）、単位「円」は不要
- 仮条件は `下限〜上限` 形式（例：`1,000〜1,200`）
- 証券コードは4桁または4桁+英字（例：`1234`、`123A`）

### 重複防止

「企業名」と「上場予定日」の組み合わせで重複チェックを行い、同一銘柄の二重登録を防ぐ。

### エラーハンドリング

- Webサイトへのアクセスに失敗した場合: 別のソースから情報を補完する
- Google Sheetsの読み込みに失敗した場合: タスクを中断し、実行ログにエラーを記録する
- Google Sheetsの書き込みに失敗した場合: 3回までリトライし、それでも失敗なら実行ログにエラーを記録して継続する
- 情報が取得できない列は空欄のままにし、次回の実行で補完する
