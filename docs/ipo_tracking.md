# IPO情報収集・一覧表管理 指示書

## 概要

2026年以降の日本株IPO（新規上場）の情報を継続的に収集し、投資判断に必要な一覧表を維持・更新するための詳細指示。
ユーザーが「IPOチェック」「IPO更新」等と発話した際、または毎日20:00の定期起動時に、本指示に基づいて情報収集→差分報告→一覧表更新を実行する。

### 管理シート

- **Google Sheets（マスター）**: https://docs.google.com/spreadsheets/d/14-W9lnTazl1fv7ck0Tmm5qYzehbFsnlw3E3e8B5URyI/edit?gid=0#gid=0
- すべての更新はこのスプレッドシートに対して行う。ローカルのxlsxファイルは使用しない。

---

## 1. 情報収集のトリガーと頻度

### 定期チェック（自動起動）
- **毎日20:00に自動起動**（スケジュール実行）
- 起動時に「新規承認」「ステータス変更」「初値確定」を確認し、Google Sheetsを更新

### 手動チェック（ユーザー発話時）
- 「IPOチェック」「IPO更新」「新規承認あった？」等の発話で起動

### 即時チェックが必要なイベント
- 新規上場承認（東証発表、通常は上場1ヶ月前）
- 仮条件決定（BB開始前後）
- 公開価格決定（BB終了翌営業日）
- 初値確定（上場日当日）
- 仮条件の上ブレ/下ブレ（想定価格との乖離）

## 4. 同業PER比較の調査方法

### 手順
1. **目論見書の「事業の内容」セクション**から比較対象企業を特定
2. 目論見書に記載がない場合、以下の基準で自分で選定：
   - 同一業種分類（東証33業種）
   - 類似ビジネスモデル（PF型/仲介型/受託型/SaaS型等）
   - 類似時価総額帯（±3倍以内）
3. **各比較企業の現在PER**をYahoo!ファイナンスまたはみんかぶから取得
4. ディスカウント幅を算出（IPO銘柄のPER ÷ 同業PER）

### 注意事項
- IFRS採用企業はのれん非償却でPERが低く見えるため、J-GAAP換算PERも併記
- 赤字企業はPSR（株価売上高倍率）で比較
- 黒字転換期の企業は実績PERが異常値になるため予想PERを使用
- M&A仲介/PF系は同業でもPER帯が10倍〜50倍と幅広い。ビジネスモデルの違い（仲介 vs PF vs SaaS）を明記

## 5. 一覧表のフォーマット

### メイン表（IPO一覧）

```
| 上場日 | 銘柄名 | コード | ランク | 主幹事 | 市場 | 時価総額(億) | 予PER | 実績PER | PBR | 同業PER | 同業企業 | 公募% | 売出% | OR% | 吸収(億) | 想定価格 | 仮条件 | 公開価格 | 初値 | 騰落率 | BB期間 | 備考 |
```

### サブ表（同業PER比較）

```
| IPO銘柄 | コード | 予PER | 同業企業名 | 同業コード | 同業PER | ディスカウント幅 | 備考 |
```

### 表記ルール
- 金額：円単位（カンマ区切り）
- 比率：%表記（小数第1位まで）
- PER/PBR：倍表記（小数第1位まで）
- 赤字企業のPER：「赤字」と記載
- 未確定項目：「未定」と記載
- 未上場銘柄：黄色ハイライト（Google Sheetsの条件付き書式）

## 6. ステータス管理

各銘柄に以下のステータスを付与し、進行状況を把握する。

| ステータス | 意味 | 次のアクション |
|-----------|------|--------------|
| 承認済 | 上場承認発表済、想定価格あり | 仮条件待ち |
| 仮条件決定 | 仮条件発表済 | BB参加判断→公開価格待ち |
| BB中 | ブックビルディング期間中 | 参加/見送り判断 |
| 公開価格決定 | 公開価格確定、当選結果待ち | 上場日待ち |
| 上場済 | 初値確定 | セカンダリー判断 or 完了 |

## 7. 差分報告のフォーマット

チェック実行時、以下の形式で報告する。

```
【前回チェック日: yyyy/mm/dd → 今回: yyyy/mm/dd】

■ 新規承認（前回以降）
- [銘柄名]（コード）上場日: mm/dd, 主幹事: ○○, 想定価格: ○○円

■ ステータス変更
- [銘柄名]: 仮条件決定 → ○○〜○○円（想定比: 上ブレ/同値/下ブレ○%）
- [銘柄名]: 公開価格決定 → ○○円（仮条件上限/下限）
- [銘柄名]: 初値確定 → ○○円（騰落率: +○%/-○%）

■ 5月上場分の新規承認: あり/なし

■ 一覧表更新: 必要/不要
```

## 8. 投資判断スコアリング（参考）

以下の基準でBB参加判断の目安スコアを算出する（10点満点）。

| 項目 | 配点 | 基準 |
|------|------|------|
| 吸収金額 | 2点 | 5億以下: 2pt / 5〜15億: 1pt / 15億超: 0pt |
| 単価 | 1点 | 1,000円以下: 1pt / 1,000円超: 0pt |
| 同業比ディスカウント | 2点 | 50%以下: 2pt / 50〜80%: 1pt / 80%超: 0pt |
| 公募比率 | 1点 | 50%超: 1pt / 50%以下: 0pt |
| VC売出なし | 1点 | VCなし or ロックアップ完全: 1pt / VC売出あり: 0pt |
| テーマ性 | 1点 | 国策テーマ/旬テーマ: 1pt / 地味: 0pt |
| カブスル評価 | 2点 | S/A: 2pt / B: 1pt / C/D: 0pt |

**7点以上: 全力BB / 5〜6点: 参加 / 3〜4点: 様子見 / 2点以下: 見送り**

## 10. 注意事項・フラグルール

### 自動フラグを立てるべき条件
- **🚩 IFRS採用**: のれん非償却。PER割安に見えるが実質は高い可能性
- **🚩 公募0%/売出100%**: 完全イグジット型。創業者・VCの出口
- **🚩 仮条件10%超下ブレ**: 需要不足のシグナル
- **🚩 吸収50億超（グロース）**: 需給重い
- **🚩 VC保有20%超**: ロックアップ解除後の売り圧力
- **🚩 親子上場**: ガバナンス懸念
- **✅ 吸収5億以下**: 需給好条件
- **✅ 単価1,000円以下**: 買いやすさプレミアム
- **✅ 配当3%超**: バリュー投資家の参入余地
- **✅ 全株ロックアップ（価格解除なし）**: 上場直後の売り圧力限定
