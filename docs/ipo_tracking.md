# IPO追跡システム 指示書

毎日20:00 JST に実行されるIPOチェックの手順を定義するドキュメント。

---

## 概要

日本の新規上場（IPO）情報を収集し、Notionデータベースに記録・更新する。  
対象は東京証券取引所（プライム・スタンダード・グロース市場）の全銘柄。

---

## 実行手順

### Step 1: IPO情報の収集

以下の検索キーワードで最新情報を取得する。  
今日の日付を使い、年月が正確になるようにクエリを生成すること。

**検索クエリ例：**
```
東証 IPO 新規上場 スケジュール 2025 公募価格
新規上場 IPO 一覧 直近
```

**参照サイト（WebFetchで取得）：**
- `https://minkabu.jp/ipo` — IPOカレンダー（公募価格・初値・騰落率）
- `https://kabutan.jp/ipo/` — IPO詳細情報
- `https://ipokiso.com/` — 申込スケジュール・仮条件情報

**収集対象期間：**
- 直近30日以内に上場した銘柄（初値情報の更新）
- 今後90日以内に上場予定の銘柄（新規登録・情報更新）
- 現在ブックビルディング（BB）申込中の銘柄

**収集する項目：**

| フィールド       | 説明                                        |
|-----------------|---------------------------------------------|
| 会社名          | 上場会社名                                  |
| 証券コード      | 4桁の銘柄コード（上場後に付与）              |
| 上場日          | 上場予定日または実際の上場日（YYYY-MM-DD）   |
| 市場            | プライム / スタンダード / グロース           |
| 公募価格        | IPO公募価格（円）                           |
| 仮条件          | 仮条件の上限・下限（例: 1200〜1400円）       |
| 初値            | 上場初日の始値（円、上場済みの場合のみ）     |
| 初値騰落率      | (初値 − 公募価格) ÷ 公募価格 × 100（%）     |
| 吸収金額        | 調達総額（百万円）                          |
| 業種            | 業種分類（例: ソフトウェア、医薬品 等）      |
| BB申込期間      | ブックビルディング期間（例: 6/5〜6/11）      |
| ステータス      | 予定 / BB中 / 上場済み                      |

---

### Step 2: Notionデータベースの確認・更新

#### 2-1. データベースの特定

`notion-search` で **"IPO管理"** を検索してデータベースを特定する。  
見つからない場合は Step 2-2 の手順で新規作成する。

#### 2-2. 新規作成（初回のみ）

`notion-create-database` で以下のスキーマのデータベースを作成する。

- **データベース名：** `IPO管理`
- **作成場所：** ワークスペースのルートページ（または既存のIPO関連ページ配下）

**プロパティ定義：**

| プロパティ名    | 型         | オプション                       |
|----------------|------------|----------------------------------|
| 会社名         | title      | —                                |
| 証券コード     | rich_text  | —                                |
| 上場日         | date       | —                                |
| 市場           | select     | プライム / スタンダード / グロース |
| 公募価格       | number     | 円                               |
| 仮条件         | rich_text  | 例: "1200〜1400"                  |
| 初値           | number     | 円                               |
| 初値騰落率     | number     | %                                |
| 吸収金額       | number     | 百万円                           |
| 業種           | select     | —                                |
| BB申込期間     | rich_text  | —                                |
| ステータス     | select     | 予定 / BB中 / 上場済み            |
| 最終更新       | date       | —                                |
| メモ           | rich_text  | —                                |

#### 2-3. データの登録・更新

収集した各IPO情報について、以下の手順で処理する：

1. データベース内を **会社名** で検索（`notion-fetch` または filter クエリ）
2. **既存エントリが見つかった場合** → `notion-update-page` で最新情報に更新
3. **存在しない場合** → `notion-create-pages` で新規追加
4. すべてのエントリの `最終更新` を **今日の日付** に設定する

---

### Step 3: 注目銘柄の分析・タグ付け

以下の条件を満たす銘柄を **「注目」** と判断し、`メモ` フィールドに理由を記入する：

- 吸収金額が **10億円（1,000百万円）以上**
- 初値騰落率が **+30% 以上**（上場済みの場合）
- 業種が **IT・テクノロジー・ヘルスケア・バイオ** 系
- 市場が **プライムまたはスタンダード**（グロース以外）

メモの例：
```
注目: 吸収金額1,200M円 / グロース上場 / IT業種 / 騰落率+45%
```

---

### Step 4: 完了サマリーの出力

処理完了後、以下の情報を出力する：

```
【IPOチェック完了】 YYYY-MM-DD 20:00 JST
━━━━━━━━━━━━━━━━━━━━━
新規登録: X 件
情報更新: X 件
上場済み（初値確定）: X 件
注目銘柄: X 件

【注目銘柄】
- <会社名>（<市場>）: 公募 <価格>円 → 初値 <価格>円（<騰落率>%）
- ...

【今後30日以内の上場予定】
- <YYYY-MM-DD> <会社名>（<市場>）公募 <価格>円
- ...
━━━━━━━━━━━━━━━━━━━━━
```

---

## エラーハンドリング

- Webサイトへのアクセスが失敗した場合は、別の参照サイトにフォールバックして情報を取得する
- Notionへの書き込みが失敗した場合は、失敗した銘柄名とエラー内容を出力して次の銘柄の処理を続ける
- データが不完全（公募価格未定など）な場合は、取得できた情報だけを登録し `ステータス` を適切に設定する

---

## 参考：ステータスの定義

| ステータス | 条件                                           |
|-----------|------------------------------------------------|
| 予定      | 上場日が未来・仮条件未発表または公募価格未定   |
| BB中      | ブックビルディング申込期間中                   |
| 上場済み  | 上場日が今日以前・初値が確定済み               |
