# IPOトラッキング指示書

## 概要

毎日20時（JST）に実行される自動IPOチェックタスクの指示書です。
日本市場の新規公開株（IPO）情報を収集し、Google Sheetsに**追記**していきます。

## 成果物

**このタスクの唯一の成果物は以下のGoogle Sheetsファイルです。**

| 項目 | 値 |
|---|---|
| ファイルID | `14-W9lnTazl1fv7ck0Tmm5qYzehbFsnlw3E3e8B5URyI` |
| URL | https://docs.google.com/spreadsheets/d/14-W9lnTazl1fv7ck0Tmm5qYzehbFsnlw3E3e8B5URyI/ |
| 対象シート | `IPO一覧`（データ蓄積）、`実行ログ`（実行履歴） |

**このファイル以外への書き込みは一切行わないこと。**

---

## 追記ポリシー（重要）

- **既存の行は削除しない**
- **既存の行は、変化のあった列のみ上書き更新する**（最終更新日も合わせて更新）
- **新規銘柄は末尾に追記する**
- 毎回の実行で情報が積み上がっていく構造を維持する

## シート構造

### シート「IPO一覧」

| 列 | ヘッダー | 説明 |
|---|---|---|
| A | 企業名 | 上場予定企業の名称 |
| B | 証券コード | 4桁（未定なら空） |
| C | 業種 | 主要業種 |

## 実行手順

### ステップ1: 既存データの読み込み

```
mcp__Google-Drive__read_file_content(fileId="14-W9lnTazl1fv7ck0Tmm5qYzehbFsnlw3E3e8B5URyI")
```

- 「IPO一覧」シートの全行を読み込む
- 既存の（企業名, 上場予定日）ペアをリスト化して重複チェックに使う

### ステップ2: 最新IPO情報の収集

以下のソースに順番にアクセスし、取得できた情報を統合する。

| 優先度 | URL | 取得内容 |
|---|---|---|
| 1 | `https://www.jpx.co.jp/listing/stocks/new/index.html` | 上場日・市場区分・証券コード |
| 2 | `https://minkabu.jp/ipo` | 申込期間・仮条件・公募価格・主幹事 |
| 3 | `https://kabutan.jp/ipo/` | 補完情報 |

1つのソースが 403 などで失敗した場合は次のソースへ移る。

### ステップ3: 差分を計算する

- **新規銘柄**: 既存シートに存在しない → 追記リストに追加
- **既存銘柄で値が変化**: 仮条件・公募価格・ステータス等が変わっていれば更新リストに追加
- **変化なし**: スキップ（書き込みしない）

### ステップ4: Sheetsへ書き込む

**新規銘柄**は「IPO一覧」シートの末尾に追記する。

**更新銘柄**は該当行の変化した列のみ上書きし、L列（最終更新日）を更新する。

書き込みに使うツール: `mcp__Google-Drive__create_file` でCSV形式の更新内容を作成するか、
接続中の Google Drive MCP サーバーが提供する spreadsheet 書き込みAPIを使う。

### ステップ5: ステータスを再計算する

全行のステータスを今日の日付（JST）で再評価して更新する。

| 条件 | ステータス |
|---|---|
| 今日 < 申込開始日 | 申込前 |
| 申込開始日 ≤ 今日 ≤ 申込終了日 | 申込中 |
| 申込終了日 < 今日 < 上場予定日 | 申込終了 |
| 今日 ≥ 上場予定日 | 上場済 |
| 中止確認済み | 中止 |

### ステップ6: 実行ログへ追記する

「実行ログ」シートの**末尾に1行追記**する（上書きしない）。

## データ品質ルール

- 日付: `YYYY/MM/DD` 形式で統一
- 金額: カンマ区切り整数（単位「円」は書かない）、例: `1,100`
- 仮条件: `下限〜上限` 形式、例: `1,000〜1,200`
- 取得できなかった列は空欄のままにし、次回以降で補完する

## 重複防止

（企業名, 上場予定日）が一致する行は同一銘柄とみなし、追記しない。

## エラーハンドリング

| エラー | 対応 |
|---|---|
| Webスクレイプ失敗（403等） | 次のソースへ移る。全ソース失敗なら実行ログにエラー記録して終了 |
| Sheets読み込み失敗 | タスクを中断し、実行ログにエラーを記録する |
| Sheets書き込み失敗 | 3回リトライ。それでも失敗なら実行ログにエラー記録して継続 |
