# IPOトラッキング指示書

## 概要

毎日20時（JST）に実行される自動IPOチェックタスクの指示書です。
日本市場の新規公開株（IPO）情報を収集し、Notionページに**追記**していきます。

## 成果物

**このタスクの唯一の成果物は以下のNotionページです。**

| 項目 | 値 |
|---|---|
| ページID | `ba01199582c243d3be0e1db8d1c50c69` |
| URL | https://www.notion.so/IPO-ba01199582c243d3be0e1db8d1c50c69 |

**このページ以外への書き込みは一切行わないこと。**

---

## 追記ポリシー（重要）

- **既存のデータは削除しない**
- **新規銘柄はページ末尾のテーブルに追記する**
- **既存銘柄は変化のあった列のみ上書き更新する**（最終更新日も合わせて更新）
- 毎回の実行で情報が積み上がっていく構造を維持する

---

## Notionページ構造

### テーブル「IPO一覧」

ページ内に以下の列を持つテーブルブロックを作成・維持する。

| 列名 | 説明 |
|---|---|
| 企業名 | 上場予定企業の名称 |
| 証券コード | 4桁（未定なら空） |
| 業種 | 主要業種 |
| 上場市場 | プライム／スタンダード／グロース |
| 申込開始日 | YYYY/MM/DD |
| 申込終了日 | YYYY/MM/DD |
| 上場予定日 | YYYY/MM/DD |
| 仮条件 | 例：`1,000〜1,200`（未定なら空） |
| 公募価格 | 例：`1,100`（未定なら空） |
| 主幹事証券 | 証券会社名 |
| ステータス | 申込前／申込中／申込終了／上場済／中止 |
| 最終更新日 | YYYY/MM/DD HH:MM（JST） |

### セクション「実行ログ」

ページ末尾に実行ログを追記していく。フォーマット:

```
### YYYY/MM/DD HH:MM JST
- 新規追加: N件
- 更新: N件
- 今日の申込開始: 銘柄名（なければ「なし」）
- 今日の申込最終: 銘柄名（なければ「なし」）
- 今日の上場: 銘柄名（なければ「なし」）
- 備考: （エラーや特記事項があれば記載）
```

## 実行手順

### ステップ1: 既存データの読み込み

```
mcp__notion__get_page(page_id="ba01199582c243d3be0e1db8d1c50c69")
```

- ページ内のIPO一覧テーブルを読み込む
- 既存の（企業名, 上場予定日）ペアをリスト化して重複チェックに使う

### ステップ2: 最新IPO情報の収集

**WebFetchは主要IPOサイトが全て403を返すため使用しない。WebSearchのみを使う。**

以下のクエリで順番に検索し、取得できた情報を統合する。

| 優先度 | 検索クエリ | 取得内容 |
|---|---|---|
| 1 | `IPO 2026年 上場予定 銘柄名 証券コード 上場日 市場` | 銘柄一覧・上場日・市場区分 |
| 2 | `IPO 2026年 申込期間 仮条件 公募価格 主幹事` | 申込期間・価格情報 |
| 3 | `IPO [企業名] [証券コード] 公募価格 仮条件 申込期間 主幹事` | 個別銘柄の詳細補完 |

検索結果のスニペットから情報を抽出する。取得できなかった項目は空欄のままにし次回補完する。

### ステップ3: 差分を計算する

- **新規銘柄**: 既存テーブルに存在しない → 追記リストに追加
- **既存銘柄で値が変化**: 仮条件・公募価格・ステータス等が変わっていれば更新リストに追加
- **変化なし**: スキップ（書き込みしない）

### ステップ4: Notionへ書き込む

**新規銘柄**はテーブルの末尾に行を追記する:
```
mcp__notion__append_block_children(page_id="ba01199582c243d3be0e1db8d1c50c69", ...)
```

**更新銘柄**は該当行の変化した列のみ上書きし、最終更新日を更新する:
```
mcp__notion__update_page(page_id=<行のブロックID>, ...)
```

### ステップ5: ステータスを再計算する

全行のステータスを今日の日付（JST）で再評価して更新する。

| 条件 | ステータス |
|---|---|
| 今日 < 申込開始日 | 申込前 |
| 申込開始日 ≤ 今日 ≤ 申込終了日 | 申込中 |
| 申込終了日 < 今日 < 上場予定日 | 申込終了 |
| 今日 ≥ 上場予定日 | 上場済 |
| 中止確認済み | 中止 |

### ステップ6: 実行ログへ追記する

ページ末尾に実行ログを1セクション追記する（既存ログは削除しない）。

### ステップ7: 成果物リンクを出力する

タスクの最後に以下のテキストを必ず出力する:

```
✅ IPOチェック完了（YYYY/MM/DD HH:MM JST）
・新規追加: N件
・更新: N件
・成果物: https://www.notion.so/IPO-ba01199582c243d3be0e1db8d1c50c69
```

---

## データ品質ルール

- 日付: `YYYY/MM/DD` 形式で統一
- 金額: カンマ区切り整数（単位「円」は書かない）、例: `1,100`
- 仮条件: `下限〜上限` 形式、例: `1,000〜1,200`
- 取得できなかった列は空欄のままにし、次回以降で補完する

## 重複防止

（企業名, 上場予定日）が一致する行は同一銘柄とみなし、追記しない。

## エラーハンドリング

| エラー | 対応 |
|---|---|
| WebSearch結果が空・情報不足 | クエリを変えて再検索。それでも取得できなければ空欄のまま次回補完 |
| Notion読み込み失敗 | タスクを中断し、実行ログにエラーを記録する |
| Notion書き込み失敗 | 3回リトライ。それでも失敗なら実行ログにエラー記録して継続 |
