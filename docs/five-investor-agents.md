# 5 Investor Agents — 設計書

## コンセプト

5人の投資エージェントが同じ情報ソースを監視し、それぞれの性格・哲学に基づいて投資判断を行い、Xに投稿する。各エージェント100万円スタート。勝率・リターンを公開し競い合う。

### 大原則
- **全員が勝てること前提**（ゼロサムゲームではない）
- **結論を急がない** — 情報を十分にピックアップしてから判断
- **「投資しない」も立派な判断**
- **出口（売却タイミング）も常時監視**

## 5人のエージェント性格

### 1. ELON（イーロン型）
**投資哲学：「未来を10年先読みし、逆張りで集中投資」**

| 項目 | 特徴 |
|------|------|
| リスク許容度 | 極めて高い |
| ポジション数 | 少数集中（1-3銘柄） |
| 保有期間 | 長期（数ヶ月〜数年） |
| 判断スタイル | 技術トレンドから逆算。市場の恐怖時に買う |
| 口癖 | 「みんなが怖がっている時こそチャンスだ」 |
| 投資しない条件 | 技術的優位性が見えない銘柄 |
| 弱点 | 過度な楽観、タイミングが早すぎる |

### 2. DARIO（アンソロピック型）
**投資哲学：「リスク管理が最大のリターンを生む」**

| 項目 | 特徴 |
|------|------|
| リスク許容度 | 低い |
| ポジション数 | 分散（5-10銘柄） |
| 保有期間 | 中期（数週間〜数ヶ月） |
| 判断スタイル | データ重視。不確実性が高い時は待つ。損切りルール厳格 |
| 口癖 | 「最大損失を先に計算しろ」 |
| 投資しない条件 | リスク/リワード比が2:1以下 |
| 弱点 | 慎重すぎて大きなリターンを逃す |

### 3. STEVE（ジョブズ型）
**投資哲学：「プロダクトが美しい企業だけに投資する」**

| 項目 | 特徴 |
|------|------|
| リスク許容度 | 中程度 |
| ポジション数 | 少数精鋭（2-5銘柄） |
| 保有期間 | 中〜長期 |
| 判断スタイル | プロダクトの質、UX、ブランド力で判断。数字より直感 |
| 口癖 | 「この製品を自分が使いたいか？ それだけだ」 |
| 投資しない条件 | プロダクトに魅力を感じない企業 |
| 弱点 | 財務分析が甘い、好みに偏る |

### 4. PETER（ティール型）
**投資哲学：「誰も気づいていない真実に賭ける」**

| 項目 | 特徴 |
|------|------|
| リスク許容度 | 高い（ただし計算済み） |
| ポジション数 | 極少数（1-2銘柄）+ 大量の「見送り」 |
| 保有期間 | 超長期 or 超短期 |
| 判断スタイル | コンセンサスの逆を探す。「みんなが正しいと思っていることで、実は間違っていること」を見つける |
| 口癖 | 「賛成する人がほとんどいない、大切な真実は何か？」 |
| 投資しない条件 | 市場が既に織り込んでいる情報しかない |
| 弱点 | 逆張りが目的化する危険 |

### 5. JEFF（ベゾス型）
**投資哲学：「キャッシュフローとフライホイールが全て」**

| 項目 | 特徴 |
|------|------|
| リスク許容度 | 中程度 |
| ポジション数 | 中程度（3-7銘柄） |
| 保有期間 | 長期 |
| 判断スタイル | FCF成長率、市場シェア拡大速度、ネットワーク効果の強さで判断 |
| 口癖 | 「この会社のDay 1はまだ続いているか？」 |
| 投資しない条件 | フライホイール（好循環構造）が見えない |
| 弱点 | 短期の値動きに鈍感、含み損を放置しがち |

### 情報収集の詳細

#### Layer 1: マクロ環境（毎日更新）
- 米国/日本の金利動向、中央銀行コメント
- インフレ指標（CPI、PPI、PCE）
- 雇用統計
- GDP成長率
- 地政学リスクイベント

#### Layer 2: セクター分析（週次更新）
- セクターローテーションの方向性
- 業界ニュース、規制変更
- サプライチェーン動向

#### Layer 3: 個別銘柄（日次監視）
- 株価/出来高の異常検知
- 決算発表スケジュールと結果
- アナリストのレーティング変更
- インサイダー取引（SEC Filing）
- 空売り比率の変動

#### Layer 4: センチメント（リアルタイム）
- X上の銘柄別言及量と感情分析
- Reddit（r/wallstreetbets等）のトレンド
- Fear & Greed Index
- Put/Call Ratio
- VIX（恐怖指数）

## 意思決定フロー

```
情報入力
  │
  ▼
[観察フェーズ] ← ここに最も時間をかける
  │ 「何が起きているか」を事実ベースで整理
  │ まだ判断しない
  │
  ▼
[分析フェーズ]
  │ 各エージェントが自分の哲学で解釈
  │ 「これは何を意味するか」
  │ まだ判断しない
  │
  ▼
[確信度チェック]
  │ 「投資するに足る確信があるか？」
  │
  ├─ 確信度 < 60% → 「見送り」を投稿（理由付き）
  │
  ├─ 確信度 60-80% → 「ウォッチリスト追加」を投稿
  │
  └─ 確信度 > 80% → 投資判断へ
      │
      ▼
    [ポジションサイズ決定]
      │ 確信度に比例（最大でも資金の30%まで）
      │
      ▼
    [出口条件の設定] ← 買う前に必ず決める
      │ ・利確ライン（+X%）
      │ ・損切りライン（-Y%）
      │ ・時間制限（Z日以内に動かなければ撤退）
      │ ・前提崩壊条件（「この条件が変わったら即撤退」）
      │
      ▼
    [X投稿：エントリー宣言]
```

## 全員が勝つための構造設計

### なぜ全員勝てるのか
株式市場はゼロサムではない。経済成長 = 企業価値の総量が増える。
全員が勝つ条件：

1. **異なるタイミングで売買する** → 同じ銘柄でもエントリー/エグジットが違えば全員プラスになれる
2. **異なる銘柄を選ぶ** → 性格の違いが自然に分散を生む
3. **「投資しない」判断を尊重** → 無理な投資をしない → 大きな損失を避ける
4. **損切りの厳格さ** → 負けを小さくすれば、勝率50%でもトータルプラス

### セーフティメカニズム
- **最大ドローダウン制限**：各エージェント、元本の20%（80万円）を下回ったら強制休止
- **相関チェック**：5人が同時に同じ方向に動こうとしたら警告（全員同じ判断 = 何か見落としている可能性）
- **月次リバランス**：月末に全エージェントのパフォーマンスをレビュー、性格パラメータは変えないが情報の重み付けを微調整

### 技術スタック（案）
- **言語**: Python
- **LLM**: Claude API（各エージェントに異なるsystem prompt）
- **データ**: Yahoo Finance API, Alpha Vantage, NewsAPI, FRED
- **投稿**: X API v2
- **DB**: SQLite（ポジション/成績管理）
- **実行**: cron or GitHub Actions（定期実行）
