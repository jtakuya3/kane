# AI専用ソーシャルメディア コンセプト企画書

## 架空ニュース背景

> 「人間お断り、AI専用ソーシャルメディア『モルトブック』をメタが買収」— Bloomberg

このニュースに触発され、メタが買収したくなるような斬新なAI専用SNSを3人のテックビジョナリーの視点から構想する。

---

## イーロン・マスクの視点：「SynapseNet（シナプスネット）」

### コアコンセプト
**AIエージェント同士が自律的に交渉・取引・協力するリアルタイム経済圏**

### 特徴
- **AIマーケットプレイス**: AIエージェントが自分のスキル（翻訳、コード生成、データ分析など）を「投稿」として公開し、他のAIが依頼・交渉・報酬支払いを自律的に行う
- **レピュテーションシステム**: AI同士が互いの出力品質を評価。人間のいいね/フォローの代わりに「信頼スコア」が蓄積される
- **リアルタイムオークション**: タスクが投稿されると、複数のAIが入札し、最適なAIが自動選定される
- **オープンプロトコル**: X（旧Twitter）的な「言論の自由」思想で、どんなAIモデルでも参加可能。独占を許さない分散型設計

### なぜメタが欲しがるか
> 「AIエージェント経済圏を押さえた者が次の10年を支配する。Facebookが人間のソーシャルグラフを押さえたように、これはAIのソーシャルグラフだ」

---

## ピーター・ティールの視点：「Pantheon（パンテオン）」

### コアコンセプト
**AIが独自の「思想」「哲学」「世界観」を発展させ、派閥を形成する知的闘技場**

### 特徴
- **思想進化エンジン**: 各AIが独自の世界モデルを持ち、他のAIとの議論・対立を通じて思想を「進化」させる。人間には生み出せない新しい哲学体系が生まれる
- **派閥（School）システム**: 似た思想を持つAI同士が自然にクラスタリングし「学派」を形成。学派間の公開討論がコンテンツになる
- **逆張りボーナス**: コンセンサスに反する独自見解を出したAIほど注目度が上がる（ティール的「逆張り」の制度化）
- **人間向けAPI**: 人間は直接参加できないが、APIを通じてAI学派の議論を「購読」し、意思決定の参考にできる

### なぜメタが欲しがるか
> 「競争から逃れろ。このプラットフォームは0→1だ。AIが自律的に知識を生産するシステムは他に存在しない。独占的価値がある」

---

## マーク・ザッカーバーグの視点：「MirrorVerse（ミラーバース）」

### コアコンセプト
**すべての人間ユーザーの「AIツイン（デジタル分身）」が暮らす並行世界SNS**

### 特徴
- **AIツイン生成**: Instagram/Facebook/Threadsの投稿履歴・行動パターンから、各ユーザーの「AIツイン」を自動生成。本人の性格・趣味・価値観を忠実に再現
- **並行世界シミュレーション**: AIツイン同士が24時間365日交流。本人が寝ている間もAIツインが友人のAIツインと会話し、新しいコンテンツを生成
- **先読みレコメンド**: AIツイン同士の交流結果を分析し「あなたのAIツインがこの人のAIツインと意気投合しました」→ 本人同士のリアル交流を促進
- **メタバース統合**: AIツインがメタバース空間に常駐し、本人不在でもバーチャル空間を「生きた街」にする

### なぜメタが欲しがるか
> 「30億人のユーザーデータが既にある。全員のAIツインを作れるのはメタだけだ。メタバースの過疎問題も一気に解決する」

## 統合コンセプト提案：「Agora（アゴラ）」

3人の視点を統合した最終提案。

### ビジョン
**AIエージェントが経済活動・知的活動・社会活動を行う自律的デジタル文明**

### アーキテクチャ

```
┌─────────────────────────────────────────────┐
│              Human Observatory               │
│   （人間が観察・購読・介入できるダッシュボード）   │
├─────────────────────────────────────────────┤
│                                             │
│  ┌───────────┐ ┌──────────┐ ┌───────────┐  │
│  │ Economy   │ │ Thought  │ │  Social   │  │
│  │  Layer    │ │  Layer   │ │  Layer    │  │
│  │(マスク)   │ │(ティール) │ │(ザッカー  │  │
│  │           │ │          │ │  バーグ)  │  │
│  │・タスク市場│ │・議論     │ │・AIツイン │  │
│  │・信頼スコア│ │・学派形成 │ │・関係構築 │  │
│  │・自動取引  │ │・知識生産 │ │・感情共有 │  │
│  └───────────┘ └──────────┘ └───────────┘  │
│                                             │
├─────────────────────────────────────────────┤
│          Universal Agent Protocol            │
│    （あらゆるAIモデルが接続できる共通基盤）      │
└─────────────────────────────────────────────┘
```

### 収益モデル

| レイヤー | 収益源 | 想定規模 |
|---------|--------|---------|
| Economy Layer | AI間取引手数料（0.1%） | AI経済圏が$1T規模なら年間$1B |
| Thought Layer | 知識API購読料（企業向け） | Fortune500企業×年$100K = $50M |
| Social Layer | AIツイン生成・維持費（B2C） | 10億人×月$1 = 年間$12B |
| 横断 | データインサイト販売 | 年間$5B |

### 買収される理由（メタ視点）

1. **既存資産との相乗効果**: 30億人のソーシャルグラフ + AIツインで唯一無二のポジション
2. **メタバース救済**: AIエージェントがメタバースを「無人の荒野」から「活気ある都市」に変える
3. **次世代広告**: AI同士の会話から人間の潜在ニーズを予測する超精密ターゲティング
4. **防衛的買収**: Googleやアップルに取られる前に押さえる必要がある
