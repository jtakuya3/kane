# SMART Consulting — Company Website

`sma-rt.jp` をベースにグレードアップした、静的コーポレートサイト。

## 特徴

- **ヒーローカルーセル**: 4枚の自動再生スライド／矢印・インジケータ・キーボード・スワイプ対応。
- **スクロール演出**:
  - 最上部に読書進捗バー（グラデーション）
  - セクションごとのフェードアップ演出（IntersectionObserver）
  - スクロール連動アクティブナビ
- **ロゴ配置**:
  - ヘッダー／フッターにブランドロゴ（SVG）
  - クライアント用のマーキー（無限横スクロール）＋静的ロゴ壁
- **カウンター**: 実績数字がビューポート進入時にカウントアップ。
- **モバイル対応**: ハンバーガー→ドロワー、`prefers-reduced-motion` 対応。
- **パレット**: ネイビー × ゴールドの信頼感のある配色、見出しは明朝体（Noto Serif JP）。

## 構成

```
website/
├── index.html
├── css/style.css
├── js/main.js
└── assets/logo.svg
```

## ローカルでの確認方法

```bash
cd website
python3 -m http.server 8000
# http://localhost:8000/ を開く
```
